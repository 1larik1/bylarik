# bylarik — будильник для Android, который ждёт отбоя тревоги

Будильник проверяет официальные данные о воздушной тревоге (siren.pp.ua) для выбранного места:
область → район → громада.

- **Тревоги нет** — звонит как обычно.
- **Тревога** — действует по правилу будильника:
  - **«После отбоя»** — ждёт отбоя и звонит через N минут после него, но не позже предельного времени.
  - **«Не будить»** — в этот день молчит.
  - **«Будить всегда»** — звонит как обычно.
- **Проверить не удалось** (нет интернета) — звонит на всякий случай.

Новости из публичных Telegram-каналов только показываются. Решение «будить или нет» принимается по официальным данным.

## Установка

1. На телефоне открой https://github.com/1larik1/bylarik/releases/tag/android-latest и скачай `bylarik.apk`
   (или возьми файл из чата).
2. Открой файл. Android спросит разрешение «Установка из этого источника» — разреши для браузера или «Файлов».
3. Запусти «bylarik» и выбери свою область (лучше сразу район).
4. Во вкладке «Ещё» → «Готовность» выдай все разрешения:
   - уведомления;
   - точное время;
   - будильник на весь экран;
   - работа без ограничений батареи.
5. Там же нажми «Проверка» — тестовый будильник сработает через минуту и пройдёт весь путь, как настоящий.

На Xiaomi, Huawei, Samsung и других дополнительно включи для «bylarik» «Автозапуск» и снимай ограничения
батареи в настройках приложения. Иначе система может «усыпить» приложение ночью.

## Обновление

Приложение само проверяет, нет ли новой версии в релизах этого репозитория:
при открытии (не чаще раза в час) и утром после срабатывания будильника.
Когда она есть, приходит уведомление, а на главном экране и в «Ещё» появляется кнопка «Обновить».
Проверить вручную можно в «Ещё» → «Версия».

Новые версии подписаны тем же ключом и ставятся поверх старой, настройки сохраняются.
Ключ хранится в кеше GitHub Actions. Если сборок не было больше недели, кеш может пропасть.
Тогда новую версию один раз придётся поставить начисто.
